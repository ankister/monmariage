Livraison sous haute tension

Le pâtissier est souffrant : c’est à toi de conduire la pièce montée jusqu’à la salle de réception. Les témoins ont parié qu’ils la voleraient avant le dessert…

Le gâteau doit arriver entier

Pause

But. Rejoins la salle de réception (flèche dorée, point doré sur la carte) avant la fin du temps, avec le gâteau le plus intact possible.

Conduite. ↑/Z accélérer, ↓/S freiner ou reculer, ← → / Q D tourner, Espace frein à main (dérapage), Maj turbo.

Les témoins. Ils te foncent dessus et, si tu t’arrêtes près d’eux, ils piquent une part. Les chocs contre les murs abîment aussi le gâteau.

Bonus. 🍰 glaçage (répare le gâteau), 🚀 turbo, ⏱ temps supplémentaire. Les parcs se traversent, le fleuve ne se franchit que par les ponts. Pause : Échap.
